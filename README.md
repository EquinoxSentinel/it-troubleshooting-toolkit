# IT Troubleshooting Toolkit

A beginner Python project designed to help diagnose common network connectivity issues using simple command-line checks.

## About the Project

The IT Troubleshooting Toolkit is my first Python project. I am building it to develop practical skills in IT support, networking, Python programming, and technical troubleshooting.

The goal is to create a small command-line tool that checks network connectivity, identifies potential problems, and provides basic troubleshooting guidance.

## Getting Started

### Requirements

* Python 3 installed
* Git installed (for version control)
* A computer running Windows, Linux, or macOS

### Run the Project

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the program:

```bash
python main.py
```

On Windows, you can also try:

```powershell
py main.py
```
